## 🔍 My Troubleshooting Method

I don't approach hardware problems by randomly replacing components.

```text
Identify Symptoms
       ↓
Understand the Failure
       ↓
Isolate the Subsystem / Component
       ↓
Check BIOS / UEFI / Drivers
       ↓
Run Diagnostic Tests
       ↓
Repair / Replace the Faulty Component
       ↓
Stress Test
       ↓
Verify Stability
```

### Example Areas

| Problem | Investigation Areas |
|---|---|
| Windows not booting | EFI, BCD, boot mode, partition structure |
| SSD not detected | BIOS, VMD, controller, firmware, physical connection |
| BSOD | Drivers, storage, RAM, thermal/power conditions |
| Laptop overheating | Cooling system, thermal paste, fan, airflow |
| Random shutdown | Power delivery, thermal limits, PSU/adapter, motherboard |
| Slow system | Storage health, RAM, thermals, Windows configuration |
| GPU crashes | Driver, temperature, power, hardware stability |
